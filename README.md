# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- Play against the computer
- Randomized computer choice each round
- Score tracking for both player and computer
- Clean card-style UI with clickable choices
- Responsive layout for desktop browsing

## How to Play

1. Open `index.html` in your browser.
2. Click one of the three choices: rock, paper, or scissors.
3. The computer makes a random move.
4. The winner is displayed and the score updates.

## Project Structure

- `index.html` — page structure and game elements
- `style.css` — styling and layout
- `script.js` — game logic and event handling
- `images/` — images used for each choice

## Run Locally

Because this is a static web app, you can simply open the `index.html` file in any browser.

If you prefer a local server, you can also run a simple static server in the project folder, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
